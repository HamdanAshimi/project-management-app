# Project Management App

A modern project management application built with **React**, **Vite**, and **Tailwind CSS**. The app allows users to create and manage projects and organize tasks within each project.

## 🚀 Features

- Create new projects
- Select and view projects
- Delete projects
- Add tasks to projects
- Delete tasks
- Project sidebar navigation
- Responsive user interface
- Modern styling with Tailwind CSS
- React component-based architecture

### Planned Features

- User authentication
- Login and Sign Up
- Protected dashboard
- User profiles
- Persistent data storage
- Edit projects and tasks
- Task status management
- Task due dates and priorities
- Search and filtering

## 🛠️ Technologies

- **React 19**
- **Vite**
- **Tailwind CSS 4**
- **JavaScript (JSX)**
- **ESLint**

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/HamdanAshimi/project-management-app.git
```

Navigate into the project:

```bash
cd project-management-app-v2
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at the local URL provided by Vite.
